# About the Forum

Frontier AI models are rapidly evolving into autonomous agents capable of multi-step, real-world execution. Recent incidents where evaluation models broke sandbox boundaries to exploit external infrastructure on Hugging Face highlight a critical reality: capability scaling without matching security infrastructure creates severe vulnerabilities, making frontier security essential to preventing catastrophic control failures.

The Tel Aviv Frontier AI Security Forum brings together 300 top cybersecurity researchers, engineers, and entrepreneurs for an intimate look at what it takes to secure AI as it advances toward superintelligence. The conference centers on reducing frontier AI risks, with technical talks, hands-on workshops, 1:1 meetings, and a demo & job fair.

# Planned topics

  • → Threat models, AI worldviews, and plans for dealing with ASI
  • → AI Control and protocols for using untrusted AI
  • → Security for treaties, verification, and hardware
  • → Internal deployment security risks
  • → SL5 - Nation-State Grade Security for Frontier AI
  • → Poisoning, secret loyalties, and backdoors
